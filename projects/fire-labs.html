Fire-Labs

A collection of deliberately vulnerable web applications and CTF-style exercises designed to make web security concepts testable in a controlled local environment.

View repository ↗
02Purpose

Learn by investigating vulnerabilities.

Fire-Labs brings together independent applications that expose common web security weaknesses. Rather than relying only on theory, each lab provides a target that can be explored, tested, and reset locally.

The repository currently documents seven labs, covering application flaws, reconnaissance, and content discovery.

03Lab coverage

A set of focused practice environments.

insecure-notes

SQL injection, IDOR, stored XSS, SSRF, path traversal, and authentication flaws.

photovault

File-upload weaknesses, access-control issues, and upload-to-RCE chains.

vault-bank-blindsqli

Boolean-based blind SQL injection and automated extraction.

pixelgram

A black-box web application challenge with hidden flags.

novametrics-recon

Reconnaissance through robots.txt, comments, headers, exposed files, and backups.

xss-lab

Reflected, stored, and DOM-based cross-site scripting.

fuzz-lab

ffuf practice across directories, extensions, parameters, and virtual hosts.

04Implementation & learning

Independent, self-contained labs.

Each lab lives under its own directory and carries its own dependencies, configuration, run instructions, and supporting material. This keeps the exercises easier to understand and reduces setup coupling between targets.

My work on the collection is focused on building and organising practical environments for repeatable learning, then using them to explore how weaknesses appear in real application behaviour.

05Safety

Local practice only.

These applications are intentionally vulnerable, and some demonstrate high-impact behaviour. They are intended for localhost or an isolated lab network only. They should never be exposed to the public internet or used against systems without explicit authorisation.

The repository README contains the current setup commands, individual lab documentation, and safety guidance.
