# Zayed Feroz Kazi — Personal Website

A small static website built with plain HTML and CSS for GitHub Pages. It has no build step or external runtime dependencies. The included `.gitignore` keeps the local `resume_and_profile.txt` working notes out of the published repository by default.

## Publish with GitHub Pages

1. Push `index.html`, `styles.css`, `assets/`, and `Zayed_Feroz_Kazi_Resume.pdf` to the root of the GitHub repository you want to use for the site. Keep the working notes out of the published repository.
2. In that repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch you pushed (usually `main`) and the `/ (root)` folder, then save.
5. GitHub will show the published URL in the Pages settings when deployment finishes.

For a profile URL such as `https://zprotons.github.io/`, the repository should be named `ZProtons.github.io`. A regular repository can also publish as a project site under `https://zprotons.github.io/<repository>/`.

The resume link expects `Zayed_Feroz_Kazi_Resume.pdf` to remain alongside `index.html` in the repository root.
